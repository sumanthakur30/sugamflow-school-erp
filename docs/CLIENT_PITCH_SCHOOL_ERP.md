## A) One-page leave-behind (print / PDF)

### SugamFlow School ERP
**Complete school operations. Configure once. Run every day.**

#### What it is
A configuration-driven School ERP with Admin, Parent, and Teacher apps — covering admissions, academics, fees, campus operations, and communication in one platform.

#### Key capabilities

| Area | Highlights |
|---|---|
| **Students** | Admission → enrollment → Student Master → Student 360 → promotions/transfers |
| **Academics** | Classes/sections, timetable, attendance, exams, report cards, homework/LMS |
| **Finance** | Fee collection, online payments, due reminders, income & expense, payroll |
| **Operations** | Library, hostel bed allocation, transport routes |
| **Comms** | Announcements to parents via In-App + Email/SMS/WhatsApp with delivery tracking |
| **Parent App** | Attendance, fees, results, report cards, homework |
| **Teacher App** | My students, attendance, gradebook, report cards, homework |
| **Admin Control** | Multi-campus, forms/workflows/rules, reports, branding (Design Studio), audit |

#### Why schools choose SugamFlow
1. End-to-end — not a fragmented toolset  
2. Configuration over customization — faster go-live, lower TCO  
3. Role-based security — parents see linked children only; teachers see assigned classes  
4. Modular plans — enable only what the school needs  
5. White-label ready — school name, logo, and theme  

#### Suggested next step
Pilot on one campus → enable core modules (Admission, Students, Fees, Attendance, Parent/Teacher apps) → expand to Library / Hostel / Transport / LMS.

**Tagline:** *The operating system for your school.*

“From admission to enrollment, student master, and Student 360 — finance, library, hostel, transport, attendance, and exams in one profile. Academics covers timetable, attendance with parent alerts, exams, report cards, and homework.”

**1:40–2:30 — Finance & ops**  
“Fees are collected with receipts and due reminders to guardians. Income-expense and payroll sit in the same finance stack. Campus ops — library, hostel, transport — are operationally ready, not just master screens.”

**2:30–3:30 — Parent & Teacher**  
“Parents open the Parent App and see only their children: attendance, fees, results, report cards, homework. Teachers open the Teacher App for assigned classes only: mark attendance, enter grades, publish report cards, assign and grade homework.”

**3:30–4:20 — Control & trust**  
“Administrators control branding, forms, workflows, menus, reports, and modules without code. Multi-campus and role-based security keep data isolated. Communication runs through Comms Hub with delivery tracking.”

**4:20–5:00 — Close**  
“SugamFlow is the operating system for your school — configure once, run every day, expand module by module. Next step: a live demo on your campus flow, then a focused pilot.”

## Quick Q&A cheat sheet

| Client question | Short answer |
|---|---|
| Can we start with only fees + attendance? | Yes — modules are subscription-gated. |
| Will parents see other students? | No — relationship-scoped to linked children. |
| Can teachers see whole school? | No — section / teacher-scope based. |
| Can we use our school branding? | Yes — Design Studio. |
| Multi-branch / multi-campus? | Yes — with campus switching and isolation. |
| Custom forms / approvals? | Yes — Form Builder + Workflow Builder. |
| Online fee payment? | Supported in finance flow (provider-configured). |
| Homework with parents? | Yes — LMS homework in Teacher + Parent apps. |
